# License and dataset inventory

> Historical private-source report, sanitized for public redistribution. Private revision references are redacted. For current public results and MIT confirmation, see [publication status](../../publication/PUBLICATION.md).

The repository already contains an MIT LICENSE in its history. Phase 5 does not
add, replace or relicense it. Owner confirmation of the existing choice is still
requested before public release.

Data is generated by `medmlops/datasets.py` and the legacy `data.py`; no external
patient dataset, scraped source or pretrained clinical model is used. Generated
cohorts are excluded from Git. The project license is not clinical approval.

`dependency-inventory.json` preserves installed package versions, declared license
expressions/classifiers/text and active dependency edges. This includes development
tools, not only runtime dependencies. It is an inventory rather than a legal opinion.

Direct stack licenses are predominantly MIT (FastAPI, Pydantic), BSD (NumPy,
SciPy, pandas, scikit-learn, Uvicorn) and Apache-2.0 (MLflow, DVC, Evidently,
Prometheus client). PostgreSQL drivers include LGPL: psycopg/psycopg-binary
declare LGPL-3.0-only; psycopg2-binary declares LGPL. Their upstream licenses and
binary notices must accompany redistributed bundles as required.

Transitive packages require attention: certifi/pathspec/shtab use MPL; orjson
declares MPL plus Apache/MIT; pygit2 declares GPLv2 with linking exception;
dulwich offers Apache-2.0 OR GPL; grandalf has a GPLv2 classifier but its installed
LICENSE offers GPLv2 OR Eclipse Public License 1.0. Do not infer a whole bundle's license
from a single classifier. Huey omits a license field/classifier but includes
`huey-3.4.0.dist-info/licenses/LICENSE`; its installed text was inspected and
contains the MIT permission grant (Charles Leifer, 2017).

Container redistribution is a separate scope: Grafana's AGPL distribution and
bundled notices, Prometheus' Apache distribution, PostgreSQL and the Python/Debian
base carry their own terms. This repository references official images and does
not publish them. No claim of completed container SBOM or legal clearance is made.
Before distributing an image or vendored environment, review complete license
files and notices (including Linux-only gunicorn/uvloop not installed on Windows),
retain required notices and produce a per-platform SBOM. Source-only GitHub
publication installs dependencies separately and must preserve this disclosure.
